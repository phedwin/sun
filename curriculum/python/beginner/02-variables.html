Variables and Data Types

Variables are containers for storing data values. In Python, you don't need to declare the type of a variable - Python figures it out automatically!

Creating Variables

To create a variable, you simply assign a value to a name:

message = "Hello, Python!"
age = 25
price = 19.99
is_student = True

Basic Data Types

1. Strings (str)

Text data enclosed in quotes:

name = "Alice"
greeting = 'Hello'
multiline = """This is a
multiline string"""

2. Integers (int)

Whole numbers without decimals:

count = 42
negative = -17
big_number = 1_000_000  # Underscores for readability

3. Floats (float)

Numbers with decimal points:

pi = 3.14159
temperature = -40.5
scientific = 2.5e-3  # 0.0025

4. Booleans (bool)

True or False values:

is_active = True
is_deleted = False

Variable Naming Rules

  • Must start with a letter or underscore
  • Can contain letters, numbers, and underscores
  • Case-sensitive (name and Name are different)
  • Cannot use Python keywords (if, for, while, etc.)

Type Checking and Conversion

# Check type
print(type(42))          # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type("Hello"))     # <class 'str'>

# Convert types
age = int("25")          # String to integer
price = float("19.99")   # String to float
text = str(100)          # Integer to string
